# Fernweh privacy policy

Static privacy policy for the Fernweh travel planner (Android, `com.fernweh.travel`), served by
GitHub Pages from the root of the main branch. English first, German below (`#de`).

The source of truth is `docs/privacy/index.html` in the app repository (`travelPlaner`); copy it
here and push. Pages redeploys in about a minute.
